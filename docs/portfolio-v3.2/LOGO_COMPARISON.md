# JF Signal — visual comparison

Three working SVG proposals were rendered in `prototypes/v3.2/brand-comparison.html` and inspected at 16, 24, 32, 48 and 64 px, on dark and light surfaces, in a desktop header and in motion.

| Criterion               | A — Signal Spine | B — Forward Relay | C — Input Fork |
| ----------------------- | ---------------: | ----------------: | -------------: |
| Legibility              |             9/10 |              7/10 |           8/10 |
| Originality             |             9/10 |              9/10 |           9/10 |
| JF recognition          |             9/10 |              6/10 |           8/10 |
| Portfolio fit           |            10/10 |              8/10 |           9/10 |
| Small-size clarity      |             9/10 |              6/10 |           7/10 |
| Motion quality          |             9/10 |              9/10 |           8/10 |
| International restraint |             9/10 |              8/10 |           8/10 |

## Decision

Proposal A was selected. Its J curve, vertical spine and two F branches stay distinct at favicon size. It also produces the clearest narrative: signal enters, travels through one system spine and reaches controlled delivery branches.

## Discarded alternatives

- B leaned too far forward. At 16–24 px the diagonal compression made the symbol read mainly as an F and weakened the J.
- C had the strongest literal input metaphor, but its detached blue entry segment became decoration at favicon size and made the static monochrome version less coherent.
